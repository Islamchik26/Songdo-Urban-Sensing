`clean_plunge_reference.csv` is a synthetic 10 Hz, 180 s, noiseless 25-to-20 C PT100 plunge at t=30 s. It was generated independently in Python using the documented exact-ZOH recurrence, not exported from MATLAB and not observed by KMA. Humidity, wind and station pressure are constant reference inputs. UTC anchor is the application's configured synthetic anchor, 2026-01-01T00:00:00.000Z by default. Use this to exercise strict CSV replay, not as a real weather benchmark.
